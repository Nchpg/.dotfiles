Configurer Dolphin

À faire une fois sur chaque PC qui lance Dolphin (Windows, macOS ou Linux). Les téléphones ouvrent ensuite simplement la page de la manette, de n'importe quel réseau.

Le PC, lui, doit être connecté au VPN avec le service Wiimote (page VPN du dashboard) : c'est par le tunnel que Dolphin reçoit la manette.

1. Déclarer le serveur

  1. Dolphin › Options › Configuration des manettes › Sources d'entrée alternatives.
  2. Cocher Activer, puis Ajouter… avec : description {{.Name}}, adresse {{.Host}}, port {{.Port}}.

La description doit être exactement {{.Name}} : les profils ci-dessous la cherchent sous ce nom.

Les copier dans le dossier Profiles/Wiimote de Dolphin :

  • Windows : %APPDATA%\Dolphin Emulator\Config\Profiles\Wiimote (anciennes installations : Documents\Dolphin Emulator\Config\Profiles\Wiimote)
  • macOS : ~/Library/Application Support/Dolphin/Config/Profiles/Wiimote
  • Linux : ~/.config/dolphin-emu/Profiles/Wiimote (Flatpak : ~/.var/app/org.DolphinEmu.dolphin-emu/config/dolphin-emu/Profiles/Wiimote)

3. Brancher les Wiimotes

  1. Dans Wii Remotes, choisir Wii Remote émulée pour chaque joueur, puis Configurer.
  2. Profil {{.Name}} J1 pour le joueur 1 (J2 pour le 2…), Charger, fermer.

Le numéro de joueur s'allume sur les diodes en bas de la manette du téléphone.

Jouer

  • Téléphone à l'horizontale, croix à gauche : Wiimote tenue de côté, pour Mario Kart (tourner comme un volant ; 2 accélérer, 1 freiner, B déraper, croix objet).
  • Téléphone à la verticale : Wiimote pointée vers l'écran. Le pointeur suit le gyroscope ; ⌖ le recentre.
