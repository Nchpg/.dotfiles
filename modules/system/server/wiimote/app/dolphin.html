    01Configurer Dolphin une fois par PC

    Le PC doit être sur le VPN, avec le service Wiimote (page VPN du dashboard).

    Le serveur

    1. Options › Controllers › Alternate Input Sources
    2. Enable, puis Add : {{.Name}}, {{.Host}}, port {{.Port}}

    Les profils

      {{range .Players}}
    • Joueur {{.}}
      • {{end}}
    • Linux : ~/.config/dolphin-emu/Profiles/Wiimote
    • Windows : %APPDATA%\Dolphin Emulator\Config\Profiles\Wiimote
    • macOS : ~/Library/Application Support/Dolphin/Config/Profiles/Wiimote

    Les Wiimotes

    1. Wii Remote 1 › Emulated Wii Remote › Configure
    2. Profile {{.Name}} J1 › Load (J2 pour la Wii Remote 2, etc.)
    3. Cocher Background Input, sinon Dolphin ignore la manette hors de sa fenêtre.
    02Comment jouer
    • Chaque joueur entre son prénom avant « Connecter » : il apparaît dans Manettes, où l’hôte change l’ordre ou retire quelqu’un.
    • Horizontale, haut du téléphone à gauche : Mario Kart. Volant, 2 accélérer, 1 freiner, B déraper, croix objet.
    • Verticale (⟲ en haut à droite) : pointer l’écran. ⌖, viser le coin haut gauche et appuyer, puis le coin bas droit et appuyer.
